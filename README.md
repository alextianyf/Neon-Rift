# Neon-Rift

霓虹裂隙：一款网页端俯视角 Roguelite 射击游戏，纯静态，单人游玩。基于 Three.js + TypeScript + Vite。

**在线试玩：** https://alextianyf.github.io/Neon-Rift/ （每次推送到 `main` 自动部署）

> 现实被撕开维度裂隙，几何形态的"病毒体"从裂隙中涌出。驾驶机甲，深入裂隙，清除感染源。

**设计文档：** [docs/](docs/README.md)（机体、技能、武装、模块、敌人的完整数值，以及平衡规则）

## 开发

需要 Node.js 18+。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:8173，改代码自动刷新
npm run typecheck  # 只做类型检查
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 本地预览打包结果
```

`dist/` 是纯静态文件，可以直接部署到 GitHub Pages、Cloudflare Pages 或 itch.io（把 `dist/` 打成 zip 上传为 HTML 游戏即可）。

### 测试链接

在地址后面加 `?test` 打开测试模式，例如 http://localhost:8173/?test 或 https://alextianyf.github.io/Neon-Rift/?test 。加 `&sector=13` 可以直接从第 13 扇区开局。

- 存档、局内存档和最佳纪录都存在单独的位置，不影响正式存档。测试存档一开始就解锁全部机甲和深度，并有 99999 结晶。
- 屏幕上方有 TEST 按钮（或按 F2）打开测试面板：跳到任意扇区和房间类型、在身边刷任意敌人（可选精英和数量）、无敌、清场、+500 碎片、随机拿 5 个强化。

代码：`src/core/testMode.ts`、`src/ui/testPanel.ts`

### 控制台

开发模式下，浏览器控制台里可以用 `window.game` 访问整个游戏实例（打包后不会暴露），例如：

```js
game.god = true                                                   // 无敌
game.enemies.list.forEach(e => game.enemies.damage(e, 1e9))       // 清场
game.sector.enter(10, 'boss')                                     // 直接跳到第 10 扇区首领战
game.sector.enter(15, 'boss')                                     // 最终首领（击败即通关）
```

## 玩法

- **目标与裂隙深度**：一局共 15 个扇区，打过第 15 扇区（击败该扇区的首领）即通关，可以选择继续进入无尽模式。通关会解锁下一级「裂隙深度」（最高 5 级），每级叠加一条难度规则（敌人更硬、更痛、精英更多、回复变少、首领更强），结晶奖励每级 +20%。在标题界面选择深度。
- **新手提示**：第一次遇到冲刺、技能、武装拾取、传送门、精英、机关、首领等情况时，屏幕下方会弹出一次提示。可以在暂停菜单里关闭；关掉后再打开，会从头重新提示。
- **配乐**：全部由程序实时合成，分为菜单、平静、战斗、首领四种情绪，随战况自动切换；暂停时音乐会压低。有两套配乐，在暂停菜单的「配乐」里切换：**机甲史诗**（默认，原创的重型机甲风格：D 小调、约 128 BPM、失真吉他重复段、带混响的大鼓和太鼓、铜管和英雄式圆号旋律；首领战再加上双踩底鼓、军鼓滚奏、每小节的镲片和太鼓、快速弦乐、合唱和一路爬高的圆号）和**合成器（原版）**（最早的合成器浪潮配乐，保留作备份）。音乐音量可以单独调节；右上角的按钮或 M 键可以一键开关音乐。
- **扇区地图**：每清完一个扇区，地上会裂开两道裂隙（出口），颜色对应目的地，分别通往不同类型的下一个扇区：战斗、精英（全是精英，必掉武装）、数据宝库（免费武装与模块）、挑战（坚持 30 秒，奖励高阶模块）、黑市终端（用碎片交易，并有机库终端）。每 5 个扇区一个裂隙核心首领。
- **扇区布局**：小 / 中 / 大三种尺寸，开阔场地、中央深坑（挡人不挡子弹）、L 形、平行通道四种布局。
- **波次**：战斗扇区分 2–3 波，当前波次基本清完才刷下一波。敌人都从时空裂缝中出现。
- **敌人**（主线 17 种，详见 [docs/敌人.md](docs/敌人.md)）：冲锋兵、蜂群体（成群）、射手、自爆虫（爆炸也伤敌人）、分裂体（死后分裂成蜂群）、重装兵（蓄力冲撞）、护盾兵（正面挡子弹）、狙击手（激光瞄准后锁定）、召唤者（开裂缝放蜂群）、腐蚀者（留下腐蚀液）、棱镜塔（架设后旋转扫射）、钻地者（地下追踪后破土）、复制者（不断复制自己）、链接体（成对，中间拉激光墙）、相位刺客（瞬移到身后挥砍）、修复节点（给同伴回血减伤）、镜面体（发光面反弹子弹）。第 4 扇区起战斗扇区可能有主题（蜂潮、阵地、地底、猎杀、堡垒、镜厅），每个扇区最多出现 6 种敌人。第 4 扇区起出现带金色光环的精英；第 11 扇区起精英带词缀（迅捷、护盾、爆裂、反射、光环、相位、分裂、牵引），第 25 扇区起带两个。
- **首领**：第 5 扇区是织网者；第 10 扇区从核心守卫者 / 噬地蠕虫（十节身体）里随机一个，第 15 扇区从裂隙主宰 / 镜像主机（模仿你的武装）/ 棱镜巨像（棱镜板反弹子弹）里随机一个。无尽模式里第 20、30、40、50、60 扇区依次登场回响者、蚀光之眼、攻城要塞、寄生母巢、裂隙本源，第 35、45、55 扇区是同时打两个首领的双生裂隙。完整时间表见 [docs/敌人.md](docs/敌人.md)。
- **地形机关**（第 4 扇区起，敌我通用）：数据泥沼（减速）、腐化池（持续掉血）、能量罐（连锁爆炸）、周期电网、可破坏掩体、不稳定裂缝（持续刷蜂群，必须打掉）。
- **武装**：15 把，分标准 / 进阶 / 精英三个品级，每把都有自己独有的特性（比如脉冲枪的充能节奏、冰晶枪冻成冰块、磁轨炮蓄能、蜂群导弹锁定齐射、奇点引力井），Lv3 和 Lv5 各解锁一个强化。最多带 3 把。每台机体有自己的初始武器（堡垒霰弹枪、先锋脉冲枪、幻影冲锋枪、奇点棱镜枪），弹药无限、不会被替换。拾取的武器有弹匣和有限的备弹：打空弹匣自动装弹，也可以按 R 手动装弹；重复拾取同一把会升级（每级伤害 +20%，最高 Lv5）并补满弹药，详见 [docs/武装.md](docs/武装.md)，黑市也卖弹药补给。射速和装弹速度是两项独立的属性。
- **属性上限**：冲刺冷却基础 3 秒（堡垒 3.45 秒、幻影 2.4 秒），最低 2 秒；射速最高 ×2.2；装弹时间最多快一倍、且不低于 0.8 秒；移动速度最高为机体原值的 1.4 倍，暴击率最高 60%，暴击伤害最高 ×3.5；所有「伤害 +X%」相加，最高 +200%。达到上限后对应的模块不再出现，暂停界面会标注「已达上限」。数值都在 `data/balance.ts` 的 `caps` 里。
- **首领保护**：首领单次受到的伤害不超过最大生命的 4%，每秒不超过 12%，任何首领战至少 7~8 秒，不会被一枪打死。
- **无尽模式**：第 15 扇区以后，敌人生命每扇区 ×1.04（复利），第 60 扇区以后放缓到 ×1.015；伤害每扇区 +3%，第 80 扇区以后 +1%，最高 ×4。越往后越难，但深处的难度主要来自机制而不是血量：
  - 第 16~60 扇区：每 5 个扇区一个裂隙地层，带 2 种新敌人、一个主题和一个新精英词缀（共 18 种敌人、9 个词缀）。
  - 第 61~150 扇区：每 5 个扇区解锁 2 个敌人变种（暗红色，换一种打法）；第 65 扇区起每 5 个扇区从两个深渊异变里选一个（全局规则，最多 6 个）；首领带异变形态。
  - 第 150 扇区以后：每 5 个扇区自动组合出 2 个融合体、换一条深渊法则；首领是融合首领；每 50 个扇区一个纪元首领，打败后选一个能突破属性上限的深渊强化。
  - 详见 [docs/无尽与深渊.md](docs/无尽与深渊.md)。
- **击杀掉落**：击杀普通病毒体有小概率掉落模块、武装或弹药（按 E 拾取），越强的敌人越容易掉，精英 ×4；每个扇区最多掉 2 件。模块品质越高越难掉（普通 / 稀有 / 传说约 80% / 18% / 2%），武装越贵越难掉。概率在 `data/balance.ts` 的 `killDrops` 里。
- **出口裂隙**：走进裂隙会先弹窗确认，避免捡东西时误入下一个扇区。确认后机甲被吸到裂隙中央、下蹲，然后掉进裂隙（下沉、前倾、缩小，裂隙里的光和火星往上冲），约 0.65 秒，镜头不动，之后是短暂的黑屏过场进入下一个扇区。
- **底部技能栏**：屏幕下方中间是冲刺、机体技能（带冷却遮罩和倒计时）和三把武装（显示弹药），上面一排是当前生效的状态和已装的模块。
- **元素与联动**：点燃、冰冻、闪电。燃烧 + 冰冻叠加触发「热冲击」爆炸；冰冻的敌人受闪电伤害翻倍（超导）。
- **模块（强化）**：普通 / 稀有 / 传说三档，共 31 种。传说模块里有一批会改变打法的：烈焰轨迹（冲刺留下火焰）、第五发（每 5 发带一枚火箭）、卫星刃（环绕光刃，可吞子弹）、连锁殉爆（击杀会爆炸）、相位新星（冲刺放出一圈子弹）、驻守模式（站定增伤）、玻璃大炮（伤害 ×1.8、生命减半）。
- **局内存档**：每进入一个扇区自动存档。关掉网页后，标题界面会出现「继续上一局」，从该扇区开始时的状态继续。暂停菜单里也可以「保存并退出」。
- **图鉴与战绩**：标题界面的「图鉴」记录遇到过的病毒体、获得过的武装和模块，以及最近 20 局的战绩和累计数据。
- **开局部署**：每次开局（包括重新部署、继续存档）先播一段约 3.6 秒的部署动画：四架直升机用缆绳吊着机甲从天而降，离地约 2 米时松开缆绳，机甲砸到地面（冲击波、尘土、震屏、下蹲缓冲），直升机散开飞走，镜头从低角度一路扫回俯视的游戏视角，然后才开始战斗。按任意键、点鼠标或手柄任意键：第一下跳到落地，第二下直接开打。
- **标题界面**：背景是一段循环播放的机库动画：机械臂焊接修补机甲 → 驾驶员乘升降台、走过栈桥进入胸口舱门 → 机甲从脚到头依次点亮 → 转动上身、双炮试射 → 迈步向前。菜单在左侧，右下角显示当前机体和结晶，「操作说明」单独一页（键鼠 / 手柄 / 触屏）。
- **中英双语**：首次打开按浏览器语言自动选择，标题界面右上角可以切换。
- **机库与永久成长**：每局获得裂隙结晶（至少 10 个），在机库解锁机体（默认堡垒，先锋 100、幻影 200、传说机体奇点 600 且要先打过第 15 扇区；各有专属技能，卡片颜色按稀有度）和永久天赋（每升一级更贵，含每局一次复活）。黑市里也有机库终端，局内就能升级天赋、更换机体，永久生效并马上用在这一局。

## 代码结构

```
src/
  main.ts            入口：创建 Game 并启动
  style.css          HUD 与菜单样式（机甲驾驶舱风格）
  core/              与玩法无关的底层
    graphics.ts      渲染器、场景、相机跟随、泛光后处理
    input.ts         键盘 / 鼠标 / 手柄输入
    audio.ts         WebAudio 合成音效
    music.ts         程序生成配乐：步进音序器，按情绪切换层次；合成器（原版）配乐也在这里
    epicScore.ts     「机甲史诗」配乐：失真吉他、鼓、铜管、圆号旋律、太鼓
    assets.ts        共享几何体和发光材质
    math.ts          rand / clamp 等工具
    rng.ts           可设种子的关卡随机数（局内存档按种子重建扇区）
    testMode.ts      测试链接（?test）：存档分开
    i18n.ts          中英文切换：t() 翻译函数、页面静态文字翻译
  data/              纯配置，调数值、加内容主要改这里
    weapons.ts       武装参数和特性数值（TRAITS）
    affixes.ts       精英词缀
    themes.ts        扇区主题、每个扇区的敌人名单
    strata.ts        无尽模式的裂隙地层
    bossPlan.ts      每个首领扇区出哪个首领（主线固定或几选一、随机、双生、融合、纪元）
    variants.ts      深渊敌人变种
    scaling.ts       敌人随扇区的成长（主线线性、无尽模式先复利后放缓）
    enemies.ts       敌人参数、刷怪表、首领轮换
    upgrades.ts      模块池与稀有度权重
    map.ts           扇区类型与分岔路线
    meta.ts          机体、天赋、结晶结算
    depth.ts         通关扇区、裂隙深度难度规则
    codex.ts         图鉴里的敌人说明
    en.ts            英文翻译表（以中文原文为键）
    balance.ts       全局数值（玩家、房间、精英、元素、机关、连杀）
  game/              玩法系统
    game.ts          总控：持有各系统，状态机、主循环、受伤与击杀、开局 / 阵亡 / 通关
    sector.ts        扇区流程：进入扇区、刷怪、清场判定、挑战倒计时、模块选择、出口裂隙和掉进去的动画
    controls.ts      键盘 / 鼠标 / 手柄 / 触屏按键 → 游戏动作
    menus.ts         标题界面、裂隙深度选择、机库、图鉴、操作说明
    titleScene.ts    标题背景的机库动画：焊接、驾驶员登机、机甲启动、试射、前进，24 秒循环；长焦镜头、景深、调色和颗粒（滤镜在 core/graphics.ts，只在标题界面开启）
    progress.ts      写进存档的长期进度：图鉴、战绩、最佳纪录、深度解锁
    player.ts        玩家移动、冲刺、射击、瞄准、技能（含奇点的轨道湮灭）
    clones.ts        幻影的分身技能：跟随、复制射击、吸引敌人、被打碎
    barrier.ts       堡垒的电磁屏障特效：能量罩、环绕光环、地面光圈
    orbitalFx.ts     奇点「轨道湮灭」的表现：横幅、瞄准环和激光、肩炮蓄力、冲天光柱、天降光柱、焦痕、白闪
    intro.ts         开局部署动画：四架直升机用缆绳吊着机甲降下、松钩落地、镜头切回游戏视角（任意键跳过）
    mech.ts          机甲模型与动画；四台机体各自的上半身和武器（buildBastion 等），以及标题和机库用的精细版本
    enemies.ts       敌人生成、受伤、死亡、元素状态与联动
    enemyAI.ts       每种敌人与首领的行为
    enemyParts.ts    敌人部件：移动、攻击、特殊能力、死亡效果，新敌人由部件拼成（主线新敌人）
    partsEndless.ts  无尽地层敌人的部件，以及它们对受伤、碰到玩家、死亡的反应
    bosses.ts        主线新首领（棱镜巨像、噬地蠕虫、镜像主机）、首领部件、双生裂隙
    bossesEndless.ts 无尽首领（回响者、蚀光之眼、攻城要塞、寄生母巢、裂隙本源）
    bossForms.ts     首领异变形态、融合首领
    abyss.ts         深渊异变、深渊法则（其他系统从这里查询当前生效的规则）
    fusion.ts        融合体：从两个敌人的部件自动组合新敌人
    epoch.ts         纪元奖励、深渊强化
```

### 常见扩展方式

- **加武装**：在 `data/weapons.ts` 加一项（射速、弹道、穿透、反弹、爆炸、元素等都是配置项），再在 `core/audio.ts` 的 `sfx.shoot` 里加同名音效，`ui/icons.ts` 加图标。
- **加敌人**：在 `data/enemies.ts` 加参数并登记到 `SPAWN_TABLE`，用 `parts` 选部件（缺的部件在 `game/enemyParts.ts` 或 `game/partsEndless.ts` 里加），在 `game/enemyModels.ts` 写外观，在 `data/codex.ts` 写图鉴说明，在 `data/variants.ts` 写它的深渊变种。用部件拼成的敌人会自动进入第 150 扇区以后的融合体候选。最早的 9 种敌人的行为在 `game/enemyAI.ts`。
- **加首领**：参数写在 `data/enemies.ts`（`boss: true`），行为写在 `game/bosses.ts` 或 `game/bossesEndless.ts` 并登记到对应的 `*_AI` 表，在 `data/bossPlan.ts` 安排出场扇区，在 `bossesEndless.ts` 的 `SIGNATURE` 里给它一个标志性招式（裂隙本源和融合首领会借用）。
- **加模块**：在 `data/upgrades.ts` 加一项并指定稀有度；如需新属性，在 `game/player.ts` 加字段并在 `reset()` 里重置。
- **加机体 / 天赋**：在 `data/meta.ts` 加一项；新技能在 `Player.trySkill()` 里实现。
- **加文字**：界面文字一律用中文写，并包在 `t('...')` 里（带数字的写成 `t('扇区 {n}', { n })`），再在 `data/en.ts` 里加上对应的英文。漏掉的英文会直接显示中文。
- **改版本号**：改 `package.json` 里的 `version`（或运行 `npm version 0.7.0 --no-git-tag-version`），标题界面右下角会自动显示。
