# Neon-Rift

霓虹裂隙：一款网页端俯视角 Roguelite 射击游戏，纯静态，单人游玩。基于 Three.js + TypeScript + Vite。

**在线试玩：** https://alextianyf.github.io/Neon-Rift/ （每次推送到 `main` 自动部署）

> 现实被撕开维度裂隙，几何形态的"病毒体"从裂隙中涌出。驾驶机甲，深入裂隙，清除感染源。

## 开发

需要 Node.js 18+。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:8173，改代码自动刷新
npm run typecheck  # 只做类型检查
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 本地预览打包结果
```

`dist/` 是纯静态文件，可以直接部署到 GitHub Pages、Cloudflare Pages 或 itch.io（把 `dist/` 打成 zip 上传为 HTML 游戏即可）。

开发模式下，浏览器控制台里可以用 `window.game` 访问整个游戏实例（打包后不会暴露），例如：

```js
game.player.invuln = 999                                          // 无敌
game.enemies.list.forEach(e => game.enemies.damage(e, 1e9))       // 清场
game.enterRoom(10, 'boss')                                        // 直接跳到第 10 扇区首领战
game.enterRoom(15, 'boss')                                        // 最终首领（击败即通关）
```

## 玩法

- **目标与裂隙深度**：一局共 15 个扇区，击败第 15 扇区的裂隙主宰即通关，可以选择继续进入无尽模式。通关会解锁下一级「裂隙深度」（最高 5 级），每级叠加一条难度规则（敌人更硬、更痛、精英更多、回复变少、首领更强），结晶奖励每级 +20%。在标题界面选择深度。
- **新手提示**：第一次遇到冲刺、技能、武装拾取、传送门、精英、机关、首领等情况时，屏幕下方会弹出一次提示。可以在暂停菜单里关闭；关掉后再打开，会从头重新提示。
- **配乐**：程序生成的合成器配乐，分为菜单、平静、战斗、首领四种情绪，随战况自动切换；暂停时音乐会压低。音乐音量可以单独调节。
- **扇区地图**：每清完一个扇区，出口会出现两个传送门，分别通往不同类型的下一个扇区：战斗、精英（全是精英，必掉武装）、数据宝库（免费武装与模块）、挑战（坚持 30 秒，奖励高阶模块）、黑市终端（用碎片交易）。每 5 个扇区一个裂隙核心首领。
- **扇区布局**：小 / 中 / 大三种尺寸，开阔场地、中央深坑（挡人不挡子弹）、L 形、平行通道四种布局。
- **波次**：战斗扇区分 2–3 波，当前波次基本清完才刷下一波。敌人都从时空裂缝中出现。
- **敌人**：冲锋兵、蜂群体（成群）、射手、自爆虫（爆炸也伤敌人）、分裂体（死后分裂成蜂群）、重装兵（蓄力冲撞）、护盾兵（正面挡子弹）、狙击手（激光瞄准后锁定）、召唤者（开裂缝放蜂群）。第 4 扇区起出现带金色光环的精英。
- **首领**：核心守卫者 → 织网者（旋转激光、地雷、自爆虫）→ 裂隙主宰（穿越裂隙瞬移、弹幕螺旋、精英护卫），之后循环。
- **地形机关**（第 4 扇区起，敌我通用）：数据泥沼（减速）、腐化池（持续掉血）、能量罐（连锁爆炸）、周期电网、可破坏掩体、不稳定裂缝（持续刷蜂群，必须打掉）。
- **武装**：9 把，最多带 3 把。重复拾取同一把会升级（每级伤害 +25%）。
- **元素与联动**：点燃、冰冻、闪电。燃烧 + 冰冻叠加触发「热冲击」爆炸；冰冻的敌人受闪电伤害翻倍（超导）。
- **模块（强化）**：普通 / 稀有 / 传说三档，约 24 种。
- **机库与永久成长**：每局结束获得裂隙结晶，在机库解锁机体（先锋 / 堡垒 / 幻影，各有专属技能）和永久天赋（含每局一次复活）。
- **每日挑战**：同一天所有人的扇区生成相同（日期种子），记录当日最佳分数。

## 代码结构

```
src/
  main.ts            入口：创建 Game 并启动
  style.css          HUD 与菜单样式（机甲驾驶舱风格）
  core/              与玩法无关的底层
    graphics.ts      渲染器、场景、相机跟随、泛光后处理
    input.ts         键盘 / 鼠标 / 手柄输入
    audio.ts         WebAudio 合成音效
    music.ts         程序生成配乐（步进音序器，按情绪切换层次）
    assets.ts        共享几何体和发光材质
    math.ts          rand / clamp 等工具
    rng.ts           可设种子的关卡随机数（每日挑战）
  data/              纯配置，调数值、加内容主要改这里
    weapons.ts       武装参数
    enemies.ts       敌人参数、刷怪表、首领轮换
    upgrades.ts      模块池与稀有度权重
    map.ts           扇区类型与分岔路线
    meta.ts          机体、天赋、结晶结算
    depth.ts         通关扇区、裂隙深度难度规则
    balance.ts       全局数值（玩家、房间、精英、元素、机关、连杀）
  game/              玩法系统
    game.ts          总控：状态机、主循环、扇区流程、机库
    player.ts        玩家移动、冲刺、射击、瞄准、技能
    mech.ts          机甲模型与动画
    enemies.ts       敌人生成、受伤、死亡、元素状态与联动
    enemyAI.ts       每种敌人与首领的行为
    enemyModels.ts   敌人"病毒体"外观
    rift.ts          时空裂缝效果
    projectiles.ts   子弹、爆炸、护盾格挡（含对象池）
    room.ts          扇区尺寸与布局、碰撞、波次、传送门
    hazards.ts       地形机关
    atmosphere.ts    场景氛围：雾气、粒子、地面数据流、虚空碎片
    pickups.ts       回血球、碎片
    interactables.ts 武装掉落、黑市与宝库物品（按 E 交互）
    effects.ts       粒子（含对象池）、闪电、震屏、命中卡顿
    tutorial.ts      首次情境提示
  ui/
    hud.ts           血条、技能、分数、碎片、连杀、武装栏、提示
    screens.ts       标题 / 模块选择 / 暂停 / 结算 / 机库
    floaters.ts      伤害数字、标签、联动提示文字
    icons.ts         武装图标（SVG）
    profile.ts       永久存档（结晶、解锁、天赋、每日记录）
    settings.ts      音量、震屏、伤害数字开关
    storage.ts       最佳纪录
```

### 常见扩展方式

- **加武装**：在 `data/weapons.ts` 加一项（射速、弹道、穿透、反弹、爆炸、元素等都是配置项），再在 `core/audio.ts` 的 `sfx.shoot` 里加同名音效，`ui/icons.ts` 加图标。
- **加敌人**：在 `data/enemies.ts` 加参数并登记到 `SPAWN_TABLE`，在 `game/enemyAI.ts` 写行为，在 `game/enemyModels.ts` 写外观。
- **加模块**：在 `data/upgrades.ts` 加一项并指定稀有度；如需新属性，在 `game/player.ts` 加字段并在 `reset()` 里重置。
- **加机体 / 天赋**：在 `data/meta.ts` 加一项；新技能在 `Player.trySkill()` 里实现。
