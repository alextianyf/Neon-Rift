# 模块与元素

代码：`src/data/upgrades.ts`（玩法类传说模块的逐帧逻辑在 `src/game/perks.ts`，元素在 `src/game/enemies.ts`）

## 出现规则

每清完一个扇区三选一，按稀有度加权：

| 场合 | 普通 | 稀有 | 传说 |
|---|---|---|---|
| 普通扇区 | 65% | 30% | 5% |
| 首领 / 精英扇区 | — | 60% | 40% |
| 挑战扇区 | — | 40% | 60% |
| 黑市 | 30% | 55% | 15% |
| 宝库 | 20% | 60% | 20% |

拿满次数、或者对应属性到了上限的模块，不会再出现。

## 普通

| 模块 | 效果 | 可拿次数 |
|---|---|---|
| 过载弹芯 | 伤害 +20%（加法伤害池） | 5 |
| 急速扳机 | 射速 ×1.15 | 到射速上限（×2.2）为止 |
| 快速装填 | 装弹速度 ×1.25 | 到装弹上限为止 |
| 扩容弹匣 | 弹匣容量 ×1.3 | 3 |
| 强化外壳 | 最大生命 +25，并回复 25 | 4 |
| 轻量推进 | 移动速度 ×1.1 | 到速度上限（×1.4）为止 |
| 相位冲刺 | 冲刺冷却 ×0.75 | 3（到 2 秒为止） |
| 精准校准 | 暴击率 +8% | 到 60% 为止 |
| 磁力回收 | 碎片获取 ×1.3，拾取范围 ×1.4 | 无限 |
| 紧急维修 | 回满生命 | 只在生命低于 80% 时出现 |

## 传说

除卫星刃外都只能拿一次。

| 模块 | 效果 |
|---|---|
| 冲刺爆破 | 冲刺时在原地爆炸：半径 3，伤害 40 × 伤害倍率 |
| 能量护盾 | 每个扇区抵挡一次伤害 |
| 追踪弹头 | 子弹自动追踪附近敌人 |
| 元素大师 | 三种元素几率各 +10%，元素伤害 ×2 |
| 狂热协议 | 生命低于 50% 时射速 ×1.5 |
| 烈焰轨迹 | 冲刺留下 2.6 秒的火焰地面（半径 1.1），点燃踩上去的敌人 |
| 第五发 | 每第 5 次射击额外发射一枚火箭（火箭炮伤害） |
| 卫星刃 | 2 片光刃绕机体旋转（半径 2.4），每次切中造成 16 × 伤害倍率，并吞掉敌方子弹；最多拿 2 次（4 片） |
| 连锁殉爆 | 被击杀的敌人爆炸：半径 2.3，伤害 22 × 伤害倍率，可以连锁 |
| 相位新星 | 冲刺时向四周射出 12 发当前武装的子弹（80% 伤害） |
| 驻守模式 | 站定 0.5 秒后伤害 ×1.5、射速 ×1.25（脚下光环变金色） |
| 玻璃大炮 | 伤害 +60%（加法伤害池），最大生命减半 |

## 元素与协同

| 元素 | 效果 |
|---|---|
| 燃烧 | 持续 3 秒，每秒 7 × 伤害倍率 × 元素倍率 |
| 冰冻 | 持续 2 秒，移动速度 ×0.45（受敌人抗性影响） |
| 闪电链 | 跳向 5.5 米内最近的 3 个敌人，每个受到命中伤害 60% × 元素倍率；对冰冻中的敌人伤害翻倍 |
| 热冲击 | 同一敌人身上燃烧遇到冰冻（不分先后）时爆炸：伤害 (35 + 命中伤害) × 元素倍率 × 热冲击倍率，半径 2.4 |
