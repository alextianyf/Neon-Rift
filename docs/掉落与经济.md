# 掉落与经济

代码：`src/data/balance.ts`（`killDrops`、`shop`、`orbs`）、`src/game/interactables.ts`

## 武装掉落

| 来源 | 规则 |
|---|---|
| 清完扇区 | 首领、精英扇区和前 2 个扇区必掉一把武装，其他战斗扇区 30% |
| 数据宝库 | 一把免费武装 |
| 黑市 | 两把武装出售 |

掉落和商店不会出现自己机体的初始武器，会优先出现还没拿到的武装。

## 击杀掉落

击杀普通敌人（不含首领）时有小概率掉落东西，按 E 拾取，离开扇区后消失。

| 项目 | 规则 |
|---|---|
| 概率 | 2.5% × 敌人刷怪成本：蜂群体约 0.8%，冲锋兵 2.6%，射手 3.9%，护盾兵 5.6%，重装兵 7.7% |
| 精英 | 概率 ×4 |
| 数量 | 每个扇区最多 2 件 |
| 种类 | 模块 50%、武装 30%、弹药 20%（弹药满时改掉模块） |
| 模块品质 | 普通约 80%、稀有约 18%、传说约 2% |
| 武装品质 | 按价格：≤30 碎片的常见（70），35 的少见（25），≥40 的稀有（5） |

## 回复球

每个回复 15 生命（深度 4 以上 -40%）。所有扇区都一样：

| 来源 | 概率 |
|---|---|
| 普通敌人 | 敌人自己的掉落率 × 2：蜂群体 4%，自爆虫 12%，冲锋兵、分裂体、射手 16%，狙击手 20%，护盾兵 24%，召唤者 30%，重装兵 100%（之前是这些的一半） |
| 精英 | 上面的概率再 +60% |
| 爆炸桶 | 被打爆时 30% |
| 掩体 | 被打碎时 40% |
| 不稳定裂缝 | 封闭时必掉 2 个 |

## 黑市

| 商品 | 价格（碎片） |
|---|---|
| 武装 | 武装价格（25~45） |
| 模块 | 普通 20、稀有 35、传说 60 |
| 维修包 | 15（回复 40 生命） |
| 弹药补给 | 12（补满所有拾取武装的备弹） |
| 机库终端 | 免费打开，用裂隙结晶升级天赋、解锁或更换机体，见 [机体与天赋.md](机体与天赋.md) |

每过 5 个扇区，黑市价格 +15%；深度 4 以上再 +25%。

## 数据宝库

一把免费武装、一个免费模块，以及一堆碎片（15 + 扇区 × 2）。
